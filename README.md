## Projects

### 1. Battery Charger with Live Power Monitor *(in progress)*
- Charging stage designed and simulated in **LTspice** (TIP29C transistor stage, 8.2 V zener reference)
- **INA219** current/voltage sensing with hardware averaging and software smoothing
- Live dashboard on a 2" ST7789 TFT, driven by an Arduino Uno
- Transformer enclosure modeled in **Onshape** and 3D-printed

### 2. Handheld Tetris on Arduino
- Full Tetris written from scratch in C++ for an Arduino Uno
- All 7 pieces stored as bitmasks in flash, with rotation, wall kicks, line clearing and scoring
- 2" color TFT over SPI with five push-button controls
